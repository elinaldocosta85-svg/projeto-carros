# Portfólio Elinaldo Costa

Projeto Front-End acadêmico desenvolvido a partir do arquivo HTML original enviado.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Estrutura
- `index.html` — estrutura do site
- `styles.css` — estilos e responsividade
- `script.js` — menu mobile, formulário e ano automático
- `img/` — imagens do projeto

## Como executar
Abra o arquivo `index.html` no navegador.

## Publicação
O projeto pode ser enviado para um repositório no GitHub ou GitLab e depois vinculado a um quadro no Trello.
